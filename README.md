# Lab-11
# Лабораторна робота №11: Розв’язування задач з використанням структур

**Тема:** Оголошення структур у мові програмування C++, робота з полями структур та обчислення часових інтервалів.

## Виконані завдання

1. **Задача 1 (`code_1`):** реалізація структури `Date` з полями `hours` і `minutes` (зі значеннями за замовчуванням), перевірка коректності введеного початкового часу та обчислення нового часу після додавання заданої кількості хвилин.
2. **Задача 2 (`code_2`):** обчислення тривалості події між часом початку та часом завершення за допомогою структури `Date` із перевіркою допустимих меж годин (`0..23`) та хвилин (`0..59`).

## Висновок
Під час виконання практичного заняття було засвоєно синтаксис оголошення структур у C++, ініціалізацію їх полів за замовчуванням та використання структурних змінних для зручного зберігання й обробки пов'язаних даних.
